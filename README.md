# ICAIF 2026 — AI × Market Microstructure

Astro landing page for the proposed ICAIF 2026 workshop **AI-Driven Market Microstructure in Centralized and Decentralized Finance**.

## Commands

```bash
npm install
npm run dev
npm run build
```

The abstract form is currently a frontend demo. Connect `#abstract-form` in `src/pages/index.astro` to Formspree, Google Forms, or a backend endpoint to receive submissions.
